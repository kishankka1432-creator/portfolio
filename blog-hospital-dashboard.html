How I Built My First Hospital Dashboard

June 2026 5 min read

As a second-year CSE-DS student, I wanted to apply my data analysis skills to a real-world scenario. I chose healthcare because it's data-rich and has a direct impact on people's lives. Here's how I built my first interactive hospital management dashboard using Power BI, SQL, and Excel.

The Problem

Hospital administrators need to track multiple metrics simultaneously: patient admissions, bed occupancy, doctor workload, and department-wise performance. Spreadsheets alone don't provide the real-time insights needed for quick decision-making.

My Approach

1. Data Collection & Cleaning (Excel)

I started with a synthetic hospital dataset containing patient records, admission dates, discharge dates, department assignments, and doctor information. I used Excel to clean the data — removing duplicates, standardizing date formats, and creating calculated columns for length of stay.

2. Database Design (SQL)

I normalized the data into relational tables: Patients, Doctors, Departments, and Admissions. Writing SQL queries helped me understand the relationships and prepare aggregated views for the dashboard. 

-- Bed occupancy by department
SELECT 
    d.department_name,
    COUNT(a.admission_id) as total_admissions,
    AVG(DATEDIFF(day, a.admission_date, a.discharge_date)) as avg_stay
FROM Admissions a
JOIN Departments d ON a.department_id = d.id
GROUP BY d.department_name
ORDER BY total_admissions DESC;

3. Dashboard Design (Power BI)

I imported the SQL views into Power BI and created:

  • A KPI card showing total patients, active admissions, and average wait time
  • A line chart for admission trends over time
  • A bar chart comparing department occupancy rates
  • A donut chart for patient demographics
  • Slicers for date range and department filtering

4. DAX Calculations

I wrote custom DAX measures for dynamic calculations like bed turnover rate and doctor-patient ratio. 

Bed Occupancy Rate = 
DIVIDE(
    COUNTROWS(FILTER(Admissions, Admissions[Status] = "Active")),
    SUM(Departments[Total_Beds])
)

Key Learnings

Start with clean data

80% of the work is data preparation. A well-structured dataset makes visualization much easier.

Design for the audience

Hospital admins need quick insights, not complex charts. Keep it simple and actionable.

Interactivity matters

Slicers and drill-through features let users explore data at their own pace.

SQL + Power BI is powerful

Using SQL for data modeling and Power BI for visualization creates a robust pipeline.

What's Next?

Now that I've built a solid foundation with Power BI, I'm pushing deeper into advanced analytics. I'm currently learning to connect Power BI to live SQL Server databases for real-time dashboards and exploring DAX optimization techniques to make my reports faster and more responsive. I'm also experimenting with Python-based visualization libraries like Plotly and Streamlit to create even more custom, interactive data experiences. The goal is to build dashboards that don't just display data — they tell stories and drive decisions.
