SQL Queries & Features

Advanced SQL implementation including complex JOINs, views, triggers, stored procedures, and transaction management.

Complete Patient History (6-Table JOIN) 
SELECT
    p.PATIENT_ID,
    p.PATIENT_NAME,
    p.PHONE_NUMBER,
    a.APPT_ID,
    a.APP_DATE,
    a.STATUS AS APPOINTMENT_STATUS,
    d.DOC_NAME,
    d.DOC_ID,
    dp.DEMP_NAME AS DEPARTMENT,
    ad.ADMM_ID,
    ad.ADMM_DATE,
    ad.DISCHARGE_DATE,
    r.ROOM_ID,
    r.ROOM_TYPE,
    r.FLOOR_NUMBER,
    o.ORDER_ID,
    t.TEST_NAME,
    tr.RESULT_DATE,
    tr.INTERPRETATION,
    i.INVOICE_ID,
    i.INVOICE_DATE,
    i.TOTAL_AMT,
    i.TAX,
    i.NET_AMT,
    i.PAY_STATUS
FROM PATIENT_DEMOGRAPHICS p
LEFT JOIN APPOINTMENT_OPT a ON p.PATIENT_ID = a.PATIENT_ID
LEFT JOIN DOCTOR d ON a.DOC_ID = d.DOC_ID
LEFT JOIN DEPARTMENT dp ON a.DEMP_ID = dp.DEMP_ID
LEFT JOIN ADMMISION ad ON p.PATIENT_ID = ad.PATIENT_ID
LEFT JOIN ROOM r ON ad.ROOM_ID = r.ROOM_ID
LEFT JOIN TEST_ORDER o ON p.PATIENT_ID = o.PATIENT_ID
LEFT JOIN LAB_TEST t ON o.TEST_ID = t.TEST_ID
LEFT JOIN TEST_RESULT tr ON o.ORDER_ID = tr.ORDER_ID
LEFT JOIN BILLING_INVOICE i ON p.PATIENT_ID = i.PATIENT_ID
WHERE p.PATIENT_ID = 1;
Billing Details with Patient & Items 
SELECT

WHERE i.INVOICE_ID = 1;
Department-wise Patient Count 
SELECT
    d.DEMP_ID,
    d.DEMP_NAME,
    COUNT(DISTINCT a.PATIENT_ID) AS TOTAL_PATIENTS
FROM APPOINTMENT_OPT a
JOIN DEPARTMENT d ON a.DEMP_ID = d.DEMP_ID
GROUP BY d.DEMP_ID, d.DEMP_NAME;

Transaction with Savepoints 
START TRANSACTION;

INSERT INTO BILLING_INVOICE (
    PATIENT_ID, ADMM_ID, INVOICE_DATE,
    TOTAL_AMT, TAX, NET_AMT
) VALUES (1, 1, CURDATE(), 10000, 1000, 11000);

SET @invoice_id = LAST_INSERT_ID();
SAVEPOINT invoice_created;

INSERT INTO BILLING_ITEM (
    INVOICE_ID, REF_ID, ITEM_DESCRIPTION,
    QUANTITY, UNIT_PRICE, AMT
) VALUES (@invoice_id, 201, 'Room Charges', 5, 1000, 5000);

SAVEPOINT room_charge_added;

INSERT INTO BILLING_ITEM (
    INVOICE_ID, REF_ID, ITEM_DESCRIPTION,
    QUANTITY, UNIT_PRICE, AMT
) VALUES (@invoice_id, 301, 'Lab Test Charges', 1, 3000, 3000);

-- Mistake found, rollback to savepoint
ROLLBACK TO room_charge_added;

INSERT INTO BILLING_ITEM (
    INVOICE_ID, REF_ID, ITEM_DESCRIPTION,
    QUANTITY, UNIT_PRICE, AMT
) VALUES (@invoice_id, 302, 'Blood Test Charges', 1, 2500, 2500);

COMMIT;
Rollback Example - Stock Update 
START TRANSACTION;

UPDATE MEDICINE
SET STOCK_QTY = STOCK_QTY - 50
WHERE MED_ID = 1;

UPDATE MEDICINE
SET STOCK_QTY = STOCK_QTY - 30
WHERE MED_ID = 2;

-- Mistake found, rollback all changes
ROLLBACK;

Project Workflow

End-to-end process from requirement analysis to dashboard deployment.

1

Requirement Analysis

Identified 10 hospital departments and core entities: Patients, Staff, Doctors, Rooms, Appointments, Admissions, Prescriptions, Lab Tests, and Billing. Defined relationships and data flow between all modules.

2

Database Design & Normalization

Created 15 normalized tables with proper primary keys, foreign key constraints, and AUTO_INCREMENT. Designed ENUM types for status fields and DECIMAL precision for financial data. Ensured 3NF compliance.

3

Data Population

Inserted 450+ realistic records across all tables with consistent foreign key references. Created diverse data covering all blood groups, departments, room types, and appointment statuses for comprehensive testing.

4

Advanced SQL Implementation

Built complex 6-table JOINs for patient history reports, created views for simplified access, implemented triggers for audit logging, and designed stored procedures for reusable operations. Added transaction management with savepoints for billing integrity.

5

Power BI Dashboard

Connected MySQL to Power BI via DirectQuery. Created interactive visualizations: bed occupancy gauge, department-wise patient distribution, revenue trends, appointment status breakdown, and doctor workload charts. Added slicers for date range and department filtering.
