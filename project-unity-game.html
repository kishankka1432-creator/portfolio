The Challenge

The workshop required building a functional 2D platformer within 3 days with zero prior Unity experience. The goal was to implement core game mechanics including:

  • Smooth player movement with jump physics and gravity
  • Collision detection for platforms, enemies, and collectibles
  • Enemy AI with patrol patterns and player detection
  • Level progression with checkpoints and scoring system

Technical Approach

1 Player Controller (C#) 

public class PlayerController : MonoBehaviour
{
    public float moveSpeed = 5f;
    public float jumpForce = 12f;
    private Rigidbody2D rb;
    private bool isGrounded;
    
    void Start()
    {
        rb = GetComponent<Rigidbody2D>();
    }
    
    void Update()
    {
        // Horizontal movement
        float moveInput = Input.GetAxisRaw("Horizontal");
        rb.velocity = new Vector2(moveInput * moveSpeed, rb.velocity.y);
        
        // Jump with ground check
        if (Input.GetButtonDown("Jump") && isGrounded)
        {
            rb.AddForce(new Vector2(0f, jumpForce), ForceMode2D.Impulse);
        }
    }
}

Implemented a Rigidbody2D-based controller with smooth acceleration, variable jump height, and coyote time for forgiving platforming.

2 Enemy AI System

Created a simple but effective enemy patrol system using raycasting for edge detection and player tracking within a defined radius. 

void Patrol()
{
    // Edge detection using raycast
    RaycastHit2D groundInfo = Physics2D.Raycast(edgeDetector.position, Vector2.down, 1f);
    
    if (groundInfo.collider == false)
    {
        // Flip direction at platform edges
        facingRight = !facingRight;
        transform.localScale = new Vector3(-transform.localScale.x, 1, 1);
    }
}
